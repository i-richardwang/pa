# PA 控制台 UI 规格书

本文记录跨组件、跨页面共同遵守的界面规则。具体取值定义在以下位置：

| 内容 | 定义位置 |
| --- | --- |
| 色值与语义色 | `server/src/presentation_core/tokens.css`、`design_tokens.ts` |
| 阴影、圆角、字体与主题变量 | `server/console/src/styles.css` |
| 图表常量与绘图区 | `server/src/presentation_core/chart_config.ts` |
| 各渲染宿主的显示取舍 | `server/result_view/src/scene.ts` |
| 看板栅格与瓦片尺寸 | `server/console/src/dashboard/boards/tile_sizing.ts` |
| 结果形态的声明与编译 | `docs/presentation_contract.md` |
| 时间桶与差值 | `docs/time_contract.md` |

## 1. 视觉语言

- 工作区用中性白底和细描边区分层次。彩色只用于数据系列、聚焦状态和明确的语义提示。
- 组件只使用语义令牌，不自定义颜色、阴影、圆角或字体字号。控件的静息、悬停、聚焦、停用和占位状态各自使用对应的语义令牌：悬停是中性灰底，聚焦是聚焦环。
- 内容层级靠语义色、字号档位和留白区分，不加装饰性容器。
- 主区的内容卡里不再套一层卡。图表、表格和交叉表直接使用宿主提供的内容区域。
- 控件和浮层的外观由组件的变体决定。同一种用途只有一个组件实现，外面只包一层容器。
- 动效不改变内容的位置和尺寸。用户开启"减少动态效果"时，关闭所有非必要动效。

## 2. 交互反馈

- 悬停只标示指针所在位置，不改变内容含义，也不引入新的颜色含义。
- 选中态有两种：页面上被选中的区域，和浮层菜单里被选中的行，两者样式不混用。复选框和开关的选中态使用各自组件自带的样式。
- 禁用态只表示不可操作，不给控件加上它在可用时没有的边框或底色。
- 键盘焦点必须可见。焦点和悬停同时出现时，不能叠加出第三种样式。
- 破坏性操作要么可以撤销，要么先确认。危险色只用于表示危险。
- 各级提示（成功、警告、错误等）使用同一套图标和语义色，操作完成后的回执和页面内的提示条共用这一套。
- 移除操作在用户点击时就写入数据库。回执上的"撤销"执行反向操作，只要反向操作还能执行就可以撤销。因此，要支持撤销，被移除的对象必须能恢复（软删除）；无法恢复的操作只能事先确认。

## 3. 组件选择

指标域只用于目录导航，不作为查询参数。查询会根据所选指标和维度共同支持的维度范围自动规划。

### 宿主场景

结果渲染器只接受 `ViewScene` 的三种宿主场景：`card`（MCP widget 里的结果卡片）、`tile`（看板瓦片）、`page`（整页工作台）。每种场景是否显示标题、口径说明等，在 `scene.ts` 的 `VIEW_SCENES` 表里声明；绘图区留白在 `chart_config.ts` 的 `PLOT_PADDING` 表里声明，是否给绘图区画边框在同一文件的 `PLOT_FRAME` 表里声明。新增场景时在这几张表里加一行，不给组件加布尔参数。`allRows`（显示全部表格行）是全屏查看时的运行状态，不属于场景。

结果用图还是用表，由报告规格决定。查看报告的人没有图表切换开关，形态只由报告作者决定。要看底层数字，可以导出或点击单元格查看明细。

卡片只用于入口或需要强调的信息，里面不嵌套子列表。整页工作台的结果区外面不再包卡片；结果、加载中、空结果和错误四种状态占用同样的位置和尺寸。

### 常用选择

- 布尔设置用 `SwitchField`；多选成员、或带子选项的条目用 `Checkbox`。
- 页面内的分类切换和筛选使用同一种分段控件。分类切换写进 URL hash，可以收藏，也能用浏览器前进后退；筛选只存在页面状态里，不写进 URL。
- 配置栏、详情栏和能力地图的详情共用应用外框提供的右侧栏。右侧栏会把主区挤窄，而不是盖在主区上面；窄屏时改为底部抽屉（Sheet）。需要打断当前工作去查看某条记录的详情时，使用 `Sheet`。
- 记录的属性用属性列表表格展示，指标结果用结果网格展示。两者外观相近，但不能互换。

## 4. 共享组件

### 一个单元格只放一条信息

一个单元格只承载一条信息，要同时展示的多条信息拆成多列。例外有两个：人员或对象名称下方可以显示它的识别码，字典条目名称下方可以显示一句口径说明。除此之外，单元格里不堆叠属性、徽标或内部标识。界面上显示业务标题；语义成员 ID、物理字段名、英文 slug 和不面向用户的执行字段都不显示。

### Input / Textarea / Select

- 每个控件都有可访问名称，来自字段组件的标签或 `aria-label`。
- 输入内容、字段名称和选择器选项的字体字号由组件决定，调用处不覆盖。
- 选择器收起时显示业务标签，不显示内部枚举值。
- 日期和月份选择使用产品自己的组件，不用操作系统原生控件。
- 时间范围的起止月在同一个月份选择面板里编辑，写入前经过统一的时间校验。

### Button / Avatar

- 带文字的按钮是胶囊形。纯图标按钮分两种尺寸：应用外框（标题栏、侧栏等）上的大一号、正圆；内容区里的小一号、使用基础圆角。
- 调用处不覆盖按钮的颜色和尺寸，外观只通过组件变体选择。
- 代表人员的头像是圆形，代表其他对象的是方形。形状区分的是对象类型，与所在页面无关。
- 图表的系列配色和表格色阶使用同一个取色组件。

### Checkbox / Switch

开关的标签在左边，开关在右边。布尔设置不用复选框，复选框只用于多选或带子选项的条目。

### 分段控件与键盘 Esc

分段控件用于同一控制条里互斥的几个选项。绑定 URL hash 的分段控件用来切换同一类对象的不同子集；控制条左侧的控件用来筛选、分组或排序当前页面的列表。

Esc 键由应用外框统一处理：有浮层打开时关闭浮层，否则收起右侧详情栏。右侧配置栏不响应 Esc，只能通过它的开关收起。

### Menu / Popover / Command

菜单和浮层使用统一的背景材质、行结构、关闭方式和键盘行为。固定选项用 `popover-list.tsx`，可搜索的选项用 `autocomplete.tsx`，页面里不另写一套选择面板。

### Dialog / Sheet

- Dialog 只用于需要提交或确认的操作表单；查看结果用工作台或详情栏。
- 弹层使用统一的遮罩、背景和关闭按钮。有"取消"按钮时，按钮区和内容区之间有分隔；只有一个主按钮时，不额外留出空的按钮区。
- 弹层上再打开弹层时，保留下层的上下文，键盘焦点只在最上层内移动。

### Tooltip / Toast / 空状态 / 加载

- Toast 是操作完成后的回执，固定显示在同一位置，不承载页面内容。
- 空状态包含标题、说明和下一步操作。搜索无结果和"还没有任何数据"是两种不同的状态。
- 区域内容加载中统一使用 `LoadingMark`。按钮里的转圈只表示该操作正在执行，不是单独的加载状态。
- 等待时不显示倒计时、轮换的提示文字或假进度条。

## 5. 图表与结果网格

只有在当前宿主里确实能打开明细的单元格，才显示成可点击的样子；打不开明细的单元格不显示点击效果。

### 图表

- 图表用 SVG 渲染，图例用 HTML，图例和读数区用同一套系列标记。
- 各种结果（图表、排行、表格）都放在宿主提供的同一块绘图区域里。是否给这块区域画边框由宿主场景决定，与结果是图还是表无关。外层不再重复加边框，坐标轴也不再画一条和边框重合的线。
- 场景尺寸影响刻度的疏密，刻度和绘图区的计算统一在图表配置里完成。
- 单系列的横向条形图用排行样式，多系列用普通图表。百分比和百分点不共用同一根数值轴。
- 切换图形和切换聚焦系列时，颜色立即变化，不加过渡。未被聚焦的系列统一使用同一种淡色，不用透明度做出深浅不一的效果。
- 聚焦某个系列只能从读数条或已钉住的读数卡发起；鼠标在绘图区内移动只显示读数。聚焦期间只有被聚焦的系列显示数值标签，绘图区的边界不因聚焦而移动。
- 读数卡（`ReadoutCard`）是跟随鼠标的浮层，和菜单属于同一层级，使用相同的背景材质，但背景模糊比菜单弱一档。读数卡始终显示在结果区域以内。没有钉住时，读数卡不响应鼠标，点击后被钉住，此时可以在卡上聚焦系列、下钻明细，指针也停留在被钉住的那个位置上。
- 有类目轴的图表，每个类目对应一张读数卡，卡里每个系列一行。饼图没有类目轴，读数卡一次列出所有扇区，不区分"当前"扇区，因此饼图上也没有跟随鼠标移动的指示线。
- 读数卡里的差值始终用中性色，带正负号，不按涨跌着色。
- 总体值和差值由服务端给出，前端不根据可见的明细行重新汇总。

### 结果网格

- 总计行和明细行的列含义相同。总计行不参与明细的排序、截断行数的计算和明细查看。
- 总计行里的构成占比：总体指标值不为零时显示 100%，为空或为零时显示破折号。
- 表格的列轴里声明了时间时，只有结果里有时间维度才生效。单月查询的结果没有时间维度，时间列就不出现，也不提示布局失效。时间栏里的粒度切换只在查询期间窗口时出现，始终有一个选项处于选中状态：跨几年就按年，跨几个月就按月。
- 空值统一显示破折号。单元格可以查看明细这一点，只在鼠标悬停或键盘聚焦时显示出来。
- 分组边界只在多层表头里体现。横向滚动时，边缘的渐隐提示随剩余可滚动距离出现。
- 第一列是行标识时固定不动，这样向右滚动后仍能看出每行是哪一项。
- 热力着色画在单元格内部的色块上，色块和单元格边缘之间留有内边距，不会遮住行分隔线。文字颜色根据色块底色的明暗，在深色和白色之间选一种，不另设颜色。

### 整段读数

整段读数只使用服务端返回的 `presentation.totals`。它用于不按业务维度分组、指标数量少的结果，并标明实际覆盖的期间；从整段读数下钻明细时，使用同一覆盖期间。

## 6. 页面与业务工作台

### 应用外框

页面由背景画布、左侧导航栏和白色主区组成。主区是唯一的内容滚动容器，里面没有居中的定宽容器，也没有第二层内边距。窄屏时配置栏改为浮层，不把结果区和设置区挤成两条窄列。

### 列表页结构

列表页由页头、控制条和一张不加外框的表格组成。很长的列表先显示条目数，展开后再列出全部条目。标题栏里的操作按钮属于整个页面，不随页面内部状态变化。

每类对象各有一个列表页：指标、维度和业务术语各有自己的表头、归属列和维护权限。归属关系（指标属于哪个指标域、维度属于哪个属性组）在列表里显示为一列，在控制条里作为筛选条件。点击行上的归属标签可以查看归属对象的详情，与查看成员详情使用同一个右侧栏。列表页的搜索框只搜索本页这类对象，跨类型查找使用全局搜索。

### 报告工作台

- 查看和编辑使用同一套渲染结构。标题直接在原位编辑，配置栏位置固定不变。
- 配置分为筛选、指标、分组三节，顺序固定。时间在页面底栏里设置，不作为第四节。
- 由指标计算出的构成占比属于指标节；分组的排序和最大显示项数在该分组行上设置。
- 维度放在哪个轴上写入语义层的 `ViewIntent`；颜色、线柱选择、数值标签和热力色阶写入单独的 `ViewPreferences`，后者对 Agent 不可见。设置面板只显示当前编译结果支持的选项。
- 成员标题必须来自业务目录，缺标题时也不能用 ID 顶替。
- 只读信息不做成禁用控件的样子。指标、维度和时间的候选项按当前草稿判断是否可用，不可用的选项在选择面板里说明原因。

### 时间栏与对照期

时间栏位于页面底栏，是查询的必要组成部分。相对窗口（如"最近 12 个月"）和绝对窗口（如"2025-01 至 2025-06"）含义不同。对照期与主期按相同的业务时间坐标对齐，差值不能下钻明细。

指标和时间互相约束候选项：当前时间设置不支持的指标、已选指标不支持的期间或粒度，都在选择之前就禁用，并显示同一条原因。如果历史保存的规格或外部请求本身存在冲突，就在运行时显示原因并阻止执行，不自动修改用户的选择。

### 看板页

每个瓦片只有一个操作按钮位置，标题和"更多操作"按钮在同一行。瓦片的结果、加载中、空结果和错误状态占用同一块内容区域。

### 数据能力地图

只有具备业务名称、且有公开成员的构件才显示在地图上。没有业务名称的构件、成员和部门树不上图，也不用物理名或语义 ID 代替。

### 侧栏

右侧栏有两种：一种挤占主区宽度、可以折叠，和主区并排；另一种是带遮罩的模态侧板，用于查看记录详情，负责遮罩、焦点和关闭。两者宽度相近，但用途不同，不能互换。

导航条目按组排列，组的顺序和组内顺序都由声明决定。第一组不显示组标题。一组条目根据可见性整组显示或整组隐藏。

右侧栏按用途分两种：配置栏以放控件为主，排得紧凑；详情栏以阅读记录为主，排得宽松。边框、滚动和宽度由应用外框统一提供，页面里不再嵌套侧栏容器。

详情栏顶部是一张标题卡，显示记录身份和单值属性，下面再列出它包含的内容。所有信息都用业务语言表述，不显示物理表名或语义 ID。

### 明细弹层与名单

明细弹层用于展示受权限控制的逐条记录，不提供结果区已有的图表和布局功能。名单使用属性列表表格而不是结果网格，逐人字段不会发送给模型。

### 跨期组合表与原生观测

跨期组合表按列声明顺序显示，表头标出各列期间。观测列显示实际期次，未投放或未观测使用明确文字。空值沿用表格的缺值样式，真实零正常显示。CSV 用同一组含业务时间的列标题。普通查询混合多个来源时，期次提示与 CSV 的期次字段标出对应的指标。

报告编辑器按组合列显示期间选择，观测指标可按期次编码、截止日期或日期区间选择。组合表中的自然期间按整段求值，时间提示标明“一个结果”。每列的滚动期间及其编辑提示使用该指标的实际数据截止月。切换指标或筛选后，预览入口按各可用列重新检查期间和分组约束。观测列可选择单一期次或截止日期。组合表和观测结果的下载入口在表格操作区。

新建分析可以切换为跨期组合表。查询侧栏提供稳定实体维度、行基准、共享筛选，以及每列的指标和观察期间。行基准可选各列实体的并集，或任何支持该实体粒度的列。选项中的列号与表内顺序一致。两列起可运行预览。指标没有所选行粒度时，该列仍可加入并显示不可用的原因。

选择指定调研期次时列出当前账号可见的期次编码，支持输入搜索并点选。点击「应用期次」成功后收起时间面板，方便继续设置下一列。

真实期次趋势可用折线。横轴每个刻度对应一个实际期次，日期相同的独立期次按编码区分。
