# PA 控制台 UI 规格书

本文是跨组件、跨页面的形态判据源。它只说明选择边界、共享不变量和语义到实现的映射；具体数值、配方和可机械检查的约束归代码、共享令牌或测试。

## 0. 内容边界与单一事实源

只在本文保留以下内容：多个组件共同遵守且无法从代码结构直接得到的形态判据、宿主场景的取舍、用户可观察的状态边界，以及语义到实现的映射。

不在本文登记颜色、尺寸、间距、动画时长、图表常量、页面局部配方或实现过程。它们的事实源如下：

| 内容 | 事实源 |
| --- | --- |
| 色值与语义色 | `server/src/presentation_core/tokens.css`、`design_tokens.ts` |
| 阴影、圆角、字体与主题变量 | `server/console/src/styles.css` |
| 图表常量与绘图区 | `server/src/presentation_core/chart_config.ts` |
| 渲染宿主取舍 | `server/result_view/src/scene.ts` |
| 看板栅格与瓦片尺寸 | `server/console/src/dashboard/boards/tile_sizing.ts` |
| 结果形态声明与编译 | `docs/presentation_contract.md` |
| 时间桶与差值 | `docs/time_contract.md` |

能由 schema、类型、共享常量或测试守护的规则，不在这里重复实现细节。一个判断只保留在最接近其违反点的事实源；本文只承载跨文件判断。

## 1. 视觉语言

- 工作面使用中性白面和细描边建立层次；数据颜色只用于数据系列、聚焦状态和明确的语义提示。
- 控件的静息、悬停、聚焦、停用和占位状态各使用对应语义令牌。悬停使用中性灰染，聚焦使用功能性聚焦环；状态不通过调用点自定义颜色表达。
- 内容层级由语义色、字号档和留白表达，不用额外的装饰容器制造层级。
- 主区内容卡不套重复的内层卡；图表、表格和交叉表使用其宿主提供的内容面。
- 控件和浮层的形态由组件档位决定，同一语义只保留一种实现和一层容器。
- 动效不改变内容几何；用户开启减少动效时，所有非必要动效关闭。

## 2. 交互反馈通则

- 悬停只表达指针所在位置，不能改变内容语义或引入新的颜色含义。
- 选中态分为页面上的选中面和浮层中的选中行；两者不混用。复选框和开关的已选状态使用各自组件的选中态。
- 禁用态只降低可用性，不为控件添加它在可用态不存在的边框或底色。
- 键盘聚焦必须可见，且不能与悬停态叠加出另一种未定义状态。
- 破坏性操作提供撤销或确认；危险色只表示危险语义。
- 提示的级别由一套图标与语义色表达，操作回执与页内提示条共用它。
- 移除在用户点下时即落库，回执上的「撤销」调用它的逆操作：撤销窗口是逆操作还够得着的时间，
  不是尚未提交的时间。因此可撤销的移除必须在模型里可逆（软删），不可逆的动作只能给确认。

## 3. 选型判据

### 语义到实现

| 语义 | 实现 |
| --- | --- |
| 独立内容卡 | `Card` |
| 看板瓦片 | `TileShell` |
| 结果卡 | `ResultCard` |
| 整页结果区 | `ChartStage` 的 `chart-stage-result` |
| 页面分区面板 | `Frame` |
| 清单表 | 裸铺 `Table` |
| 查询结果表 | `data_table.tsx` |
| 页面分面 | `ListFacets`，绑定路由 hash |
| 筛选取值 | `DaysRangeChips` 一类分段片或控制条选择器，绑定页面状态 |
| 固定选项 | `popover-list.tsx` |
| 可搜索选项 | `autocomplete.tsx` |
| 并列工作区 | 壳的工作台右栏（`useSetStageAside`） |
| 模态档案 | `Sheet` / `SheetPopup` |
| 动作表单 / 整屏结果 | `DialogPopup` 的 `form` / `stage` 两档 |
| 右栏行 | `InspectorRow`；头卡 `InspectorProfileCard` |
| 浮层段与段题 | `PopupSection` / `PopupTitle`，宽度取 `POPUP_WIDTH` |
| 键盘聚焦 | 工具类 `pa-focus`（外壳接焦用 `pa-focus-within`） |
| 时间戳 | `formatAt` |

指标域只用于目录导航，不是查询参数。查询按所选指标与维度的共同维度空间自动规划。

### 宿主场景

渲染器只接受 `ViewScene` 枚举的 `card`、`tile`、`page` 三种宿主场景。每种场景的标题、口径说明取舍由 `scene.ts` 的 `VIEW_SCENES` 声明，绘图区留白与场地框由 `chart_config.ts` 的 `PLOT_PADDING` 声明；新增场景扩展这两张表，不增加布尔参数；`allRows` 是宿主全屏的运行态，不属场景。

呈现形态由报告规格声明，读者面不提供图与表的切换档位：同一件事只由作者表态一次。要看底层数字走导出与单元格下钻。

卡只承载入口或强调信息，不内嵌子清单。整页结果区不套结果卡，结果、加载、空和错误状态保持相同的内容几何。

### 组件选择

- 布尔设置使用 `SwitchField`；多选成员或带子选项的条目使用 `Checkbox`。
- 页内分面与筛选共用同一种分段控件：分面绑定路由 hash，可收藏、可前进后退；筛选绑定页面状态，不进路由。
- 配置栏、档案栏与地图详情共用壳排的推挤式右栏，窄屏落为底部 Sheet；需要打断当前工作读取档案时使用 `Sheet`。
- 记录属性使用清单表；指标结果使用结果网格。两者不因视觉相似而互换。

## 4. 共享组件契约

### 一格一信息

一个单元格只承载一条信息；并存的信息拆成列。主体身份可以在名称下显示辨识码，字典成员可以在名称下显示口径句，除此之外不堆叠属性、徽标或内部寻址串。界面显示业务标题，语义成员 ID、物理名和英文 slug 只用于寻址与搜索。

### Input / Textarea / Select

- 每个控件都有可访问名称，名称来自字段组件或 `aria-label`。
- 输入内容、字段名称和选择器取值各自遵循组件的排印档，不在调用点覆盖。
- 选择器闭合态显示业务标签，不显示内部枚举值。
- 日期和月份选择使用产品组件，不使用操作系统原生控件。
- 时间范围的起止值在同一个月份选择面中编辑，并通过统一时间校验边界落值。

### Button / Avatar

- 带文字按钮使用胶囊形态；纯图标按钮按壳与内容分为两档。
- 调用方不覆盖按钮的颜色和几何；组件变体是唯一的形态入口。
- 人员标识使用圆形，非人员对象使用方形；形状表达对象身份而不是所在页面。
- 取色只有一件色粒：发丝环里一粒色点，选中铺满并压反白勾；系列配色与表格色阶同用它，成排铺开就地选。

### Checkbox / Switch

开关的标签在左、控件在右。布尔设置不使用复选框，复选框只用于多选或带子选项的条目。

### 分面与分段

分段控件承载同一控制条中的互斥选项；分面是其中绑定路由 hash 的那一种用法。分面只切同一类对象的子集；控制条左槽收窄的是当前这页的清单：筛选、分组或排序。Esc 由壳统一接管：浮层开着时归浮层，否则收起档案面右栏；配置面右栏只由它的开关收起。

### Menu / Popover / Command

菜单和浮层使用统一的面料、行结构、关闭方式与键盘行为。固定选项和可搜索选项分别使用 `popover-list.tsx` 与 `autocomplete.tsx`，不在页面中另造一套选择面。

### Dialog / Sheet

- Dialog 只承载需要提交或确认的动作表单；查看结果使用工作台或档案面。
- 浮层使用统一遮罩、面料和关闭按钮。带取消动作时，动作区与内容区有明确分隔；只有主动作时不增加空的动作段。
- 浮层套浮层时保留父层上下文，并保证键盘焦点边界清晰。

### Tooltip / Toast / Empty / 加载

- Toast 是一次操作的回执，固定在统一的回执位置，不承担页面内容。
- 空态包含标题、说明和下一步动作；搜索无结果不是资源空态。
- 区域加载使用 `LoadingMark`；随行转圈只作装饰，不另认领状态名称。
- 等待态不显示倒计时、轮播话术或伪进度。

## 5. 图表与结果网格

结果面上画成可点的，只限宿主此刻真开得出明细的那一格；开不出就不给这一下的样子。

### 图表画布

- 图表使用 SVG 渲染；图例使用 HTML，与读数区域共享标记语义。
- 结果面（画布、排行、表格）共用宿主提供的同一层场地和边界，画不画框由场景决定而非形态；不在外层重复套框；坐标轴不额外绘制与边界重合的线。
- 场景尺寸影响刻度密度，但刻度和绘图区的计算由图表配置统一完成。
- 单系列横排条形使用排行版式；多系列使用画布。百分比与百分点不共用同一比例轴。
- 形态切换和聚焦换色即时完成；落选系列使用统一失焦色，不通过透明度制造多种深浅。
- 聚焦由读数条或钉住的读数卡发起；绘图区内的悬停只出读数。聚焦期间只有该系列印数值标签，绘图区边界不随聚焦移动。
- 读数卡（`ReadoutCard`）是与菜单同层的浮层，同料同框、玻璃模糊降一档；锚光标、恒夹在结果面内。未钉住时整张卡不可命中，点击钉住后由它接管命中、聚焦与下钻，钉住期间指针停在被钉的那一格。
- 有类目轴的图一格一张卡，逐系列成行；饼图没有类目轴，一张卡列齐全部切片、不认哪一片是「当前」，盘上也就不设随鼠标走的指针。
- 卡内差值恒中性并带符号，不按涨跌染色。
- 总体值和差值由服务端提供，呈现层不从可见明细行重新聚合。

### 结果网格

- 总体带与明细使用相同的列语义；总体不进入明细排序、截行计数或记录投影。
- 总体带中的构成占比在总体指标非零时显示 100%，总体指标为空或为零时显示破折号。
- 表格列轴中的时间是条件优先序：结果有时间轴才出现；单月窗口没有时间轴时它自然退场，不显示
  布局失效警告。时间栏的粒度分段只在期间窗口出现，恒有一档亮，选几年就按年、选几个月就按月。
- 空值统一显示破折号；记录的可点性只在悬停或键盘聚焦时出现。
- 组边界只在多层表头中表达；横向滚动时的边缘提示随剩余滚动空间出现。
- 首列作为坐标时保持冻结，以便数字离开视口后仍能识别所属行。
- 热力着色落在指标格内的色片上，片间留出格内衬，行线不被压断；字色按底色对比在墨色与反白间取一档，不另立色名。

### 整窗读数

整窗读数只消费服务端的 `presentation.totals`。它适用于无业务分组的少量指标，并明确标注实际覆盖期间；下钻沿用该覆盖期间。

## 6. 页面与业务工作台

### 应用壳

页面由画布、导航侧栏和主区白面组成。主区是唯一内容滚动容器；主区内部没有居中定宽层或第二道内容内衬。窄屏配置栏改为浮层，不把结果区和设置区压成并列窄列。

### 清单页骨架

清单页使用页头、控制条和一张裸铺表。长清单先显示计数，展开后再显示成员。标题栏动作属于当前这一页，页内状态不改变它。

一类对象一张清单页：指标、维度与业务术语各有自己的表头、归属列与维护权限。归属关系（指标之于指标域、维度之于属性组）出现为清单里的一列与控制条里的筛选器；归属自身的档案由行上那枚芯片点开，与成员档案同一右栏。清单页的搜索框只搜本页这类对象，跨类查找归全局搜索。

### 报告工作台

- 查看和编辑共用同一渲染结构；标题就地编辑，配置栏保持稳定位置。
- 配置分为筛选、指标和分组三节，次序固定；时间属于页面底栏，不作为第四节。
- 由指标算出的构成占比仍属于指标节；分组排序和最大项数属于分组行自身的设置。
- 呈现设置里，轴向归属（表格布局、系列的左右轴）与呈现选项（显示）分两节；前者写语义 `ViewIntent`，颜色、线柱覆盖、数值标签与热力色阶写独立 `ViewPreferences`，不得塞回 Agent 可见规格。图形的系列节按左轴、右轴分组列出已上轴的指标，右轴只在结果允许第二把尺子时出现；移轴是行内动作，显示的归属出自编译结果而非声明缺省。「显示」可折叠，表格默认展开，图形只在有偏离默认的选项时才默认展开。表格配色是一块色带预览，色阶族、取值、阈值与翻转在它点开的同一张浮层里，不各占一行；读数与阈值占位印当前结果的数据缺省，率族按表里印出来的百分数读写。开关行的说明是悬停浮出的 tooltip，不占面板高度。图形的数值标签是「显示」节里的图级三档（不显示/仅主指标/全部），不做逐系列开关；拆分系列时「仅主指标」失去所指，档位收成两档。
- 成员标题必须从业务目录获得；不能把 ID 当作界面兜底文案。
- 只读回显不伪装成禁用控件；指标、维度与时间候选按当前草稿评价，不可用项在选择面中说明原因。

### 时间栏与对照期

时间栏是查询的一等公民，位于页面底栏。相对窗口和绝对窗口表达不同语义；对照期与主期按同一业务坐标对齐，差值不参与下钻。指标与时间双向评价候选：当前时间不接受的指标、已选指标不接受的期间或粒度都在选择前禁用并说明同一原因。历史规格或外部请求形成冲突时，运行出口显示原因并阻断，不静默改写用户选择。

### 看板页

每块瓦片只有一个动作槽；标题与更多动作共用题行。瓦片的结果、加载、空和错误状态使用同一内容区。

### 数据能力地图

地图画布是一层场地：与结果面同一圈发丝框和同一档圆角，框圈住画布本身，节点、连线与取景控件都在框内。右栏是能力档案，与目录档案同一版式，排在框外与画布并列。

上图的构件必须有业务名，且有公开成员；说不出业务名的构件、成员与部门树都不上图，也不退回物理名或语义 id。

### 侧栏系统

推挤式侧栏与主区并列且可折叠；模态侧板负责档案读取并管理遮罩、焦点和关闭。两者不因宽度相近而互换。

导航条目按族分组：组序与组内序都出自声明，首组不带标签，整族按可见性一起出现或消失。

栏与主区之间那道分界线由壳画一次：它是「列与列之间」的属性。栏在窄屏改由底部侧板承载时，那道边界随之由侧板自己的上缘承担。

右栏按用途分两档，宽度与密度同出一档：配置面窄一档，段贴段、通栏分界，一屏摆得下更多控件；档案面宽一档，段落成块、分界线内缩，段题与行名左缘对齐，读的是记录本身。这一档由栏的正文发出、段与行各自认领；每条右栏都从同一个正文件开栏，自拉一个滚动容器就等于把这一档丢了。

栏里只有一种行：左边一个名字（可带图标），右边一个值或一枚控件，行外还可挂动作。清单行、设置行、事实行本是同一件东西，变的只是右槽里放什么；值那一档可截短让出空间，控件那一档不让；右槽至多占六成宽，长值不会把名字挤没。行外的动作不算这一行的内容，不吃右槽的宽。名字只在配置面让位给控件；档案面里名字就是内容本身。

档案面以一张头卡开场：图标、名字、口径，以及关于这条记录本身的几项事实（label–value 行）合在一张浅底卡里；卡下才是「它都包含什么」的分节清单。两类东西用面料分开，不靠再加几个段题分开；单值事实不配段题。档案不另设题块，名字只在卡里出现一次。

档案面的 label–value 是事实不是控件名：label 与值等重，不压成灰字。事实行只印业务的话。物理表名与语义 id 不进档案；无法用读者的语言说出的属性，整行不发。

### 明细弹层与名单卡

明细弹层承载受控记录投影，不重复结果面的呈现能力。名单使用清单表而不是结果网格，不将逐人字段放入模型上下文。

### 登录面

登录由门屏和密码卡组成。门屏只负责进入，密码卡只负责邮箱密码；登录专用输入不扩散为控制台通用表单。

## 7. 消费纪律

- 组件只消费语义令牌，不自定颜色、阴影、圆角或排印值。
- 新增跨组件形态先补充本文的判据，再由组件和测试实现；局部组件的具体配方留在组件事实源。
- 公开界面不显示内部寻址信息、物理模型名称或未面向用户的执行字段。
