# PA 控制台 UI 规格书

本文是跨组件、跨页面的形态判据源。它只说明选择边界、共享不变量和语义到实现的映射；具体数值、配方和可机械检查的约束归代码、共享令牌或测试。

## 0. 内容边界与单一事实源

只在本文保留以下内容：多个组件共同遵守且无法从代码结构直接得到的形态判据、宿主场景的取舍、用户可观察的状态边界，以及语义到实现的映射。

不在本文登记颜色、尺寸、间距、动画时长、图表常量、页面局部配方或实现过程。它们的事实源如下：

| 内容 | 事实源 |
| --- | --- |
| 色值与语义色 | `server/src/presentation_core/tokens.css`、`design_tokens.ts` |
| 阴影、圆角、字体与主题变量 | `server/console/src/styles.css` |
| 图表常量与绘图区 | `server/src/presentation_core/chart_config.ts` |
| 渲染宿主取舍 | `server/result_view/src/components/view_renderer.tsx` |
| 看板栅格与瓦片尺寸 | `server/console/src/dashboard/boards/tile_sizing.ts` |
| 结果形态声明与编译 | `docs/presentation_contract.md` |
| 时间桶与差值 | `docs/time_contract.md` |

能由 schema、类型、共享常量或测试守护的规则，不在这里重复实现细节。一个判断只保留在最接近其违反点的事实源；本文只承载跨文件判断。

## 1. 视觉语言

- 工作面使用中性白面和细描边建立层次；数据颜色只用于数据系列、聚焦状态和明确的语义提示。
- 控件的静息、悬停、聚焦、停用和占位状态各使用对应语义令牌。悬停使用中性灰染，聚焦使用功能性聚焦环；状态不通过调用点自定义颜色表达。
- 内容层级由语义色、字号档和留白表达，不用额外的装饰容器制造层级。
- 主区内容卡不套重复的内层卡；图表、表格和交叉表使用其宿主提供的内容面。
- 控件和浮层的形态由组件档位决定，同一语义只保留一种实现和一层容器。
- 动效不改变内容几何；用户开启减少动效时，所有非必要动效关闭。

## 2. 交互反馈通则

- 悬停只表达指针所在位置，不能改变内容语义或引入新的颜色含义。
- 选中态分为页面上的选中面和浮层中的选中行；两者不混用。复选框和开关的已选状态使用各自组件的选中态。
- 禁用态只降低可用性，不为控件添加它在可用态不存在的边框或底色。
- 键盘聚焦必须可见，且不能与悬停态叠加出另一种未定义状态。
- 破坏性操作提供撤销或确认；危险色只表示危险语义。

## 3. 选型判据

### 语义到实现

| 语义 | 实现 |
| --- | --- |
| 独立内容卡 | `Card` |
| 看板瓦片 | `TileShell` |
| 结果卡 | `ResultCard` |
| 整页结果区 | `ChartStage` 的 `chart-stage-result` |
| 页面分区面板 | `Frame` / `FramePanel` |
| 清单表 | 裸铺 `Table` |
| 查询结果表 | `data_table.tsx` |
| 页面分面 | `Tabs` |
| 筛选取值 | 分面片或控制条选择器 |
| 固定选项 | `popover-list.tsx` |
| 可搜索选项 | `autocomplete.tsx` |
| 并列工作区 | `ViewSidebar` |
| 模态档案 | `Sidesheet` |

指标域只用于目录导航，不是查询参数。查询按所选指标与维度的共同维度空间自动规划。

### 宿主场景

渲染器只接受 `card`、`tile`、`page` 三种宿主场景。每种场景的标题、图表切换、口径说明和绘图区取舍由 `VIEW_SCENES` 统一声明；新增场景应扩展该表，而不是增加布尔参数。

卡只承载入口或强调信息，不内嵌子清单。整页结果区不套结果卡，结果、加载、空和错误状态保持相同的内容几何。

### 组件选择

- 布尔设置使用 `Switch`；多选成员或带子选项的条目使用 `Checkbox`。
- 页内分面使用 `Tabs`，筛选使用分面片或控制条选择器；筛选不改变页面路由状态。
- 设置栏与报告工作台使用推挤式 `ViewSidebar`；需要打断当前工作读取档案时使用 `Sidesheet`。
- 记录属性使用清单表；指标结果使用结果网格。两者不因视觉相似而互换。

## 4. 共享组件契约

### 一格一信息

一个单元格只承载一条信息；并存的信息拆成列。主体身份可以在名称下显示辨识码，字典成员可以在名称下显示口径句，除此之外不堆叠属性、徽标或内部寻址串。界面显示业务标题，语义成员 ID、物理名和英文 slug 只用于寻址与搜索。

### Input / Textarea / Select

- 每个控件都有可访问名称，名称来自字段组件或 `aria-label`。
- 输入内容、字段名称和选择器取值各自遵循组件的排印档，不在调用点覆盖。
- 选择器闭合态显示业务标签，不显示内部枚举值。
- 日期和月份选择使用产品组件，不使用操作系统原生控件。
- 时间范围的起止值在同一个月份选择面中编辑，并通过统一时间校验边界落值。

### Button / Avatar

- 带文字按钮使用胶囊形态；纯图标按钮按壳与内容分为两档。
- 调用方不覆盖按钮的颜色和几何；组件变体是唯一的形态入口。
- 人员标识使用圆形，非人员对象使用方形；形状表达对象身份而不是所在页面。

### Checkbox / Switch

开关的标签在左、控件在右。布尔设置不使用复选框，复选框只用于多选或带子选项的条目。

### Tabs

Tabs 只承载页面分面；分段控件只承载同一控制条中的互斥选项。两者不因文字数量相近而互换。

### Menu / Popover / Command

菜单和浮层使用统一的面料、行结构、关闭方式与键盘行为。固定选项和可搜索选项分别使用 `popover-list.tsx` 与 `autocomplete.tsx`，不在页面中另造一套选择面。

### Dialog / Sheet

- Dialog 只承载需要提交或确认的动作表单；查看结果使用工作台或档案面。
- 浮层使用统一遮罩、面料和关闭按钮。带取消动作时，动作区与内容区有明确分隔；只有主动作时不增加空的动作段。
- 浮层套浮层时保留父层上下文，并保证键盘焦点边界清晰。

### Tooltip / Toast / Empty / 加载

- Toast 是一次操作的回执，固定在统一的回执位置，不承担页面内容。
- 空态包含标题、说明和下一步动作；搜索无结果不是资源空态。
- 区域加载使用 `LoadingMark`；随行转圈只作装饰，不另认领状态名称。
- 等待态不显示倒计时、轮播话术或伪进度。

## 5. 图表与结果网格

### 图表画布

- 图表使用 SVG 渲染；图例使用 HTML，与读数区域共享标记语义。
- 绘图区只由宿主提供一层场地和边界，不在外层重复套框；坐标轴不额外绘制与边界重合的线。
- 场景尺寸影响刻度密度，但刻度和绘图区的计算由图表配置统一完成。
- 单系列横排条形使用排行版式；多系列使用画布。百分比与百分点不共用同一比例轴。
- 形态切换和聚焦换色即时完成；落选系列使用统一失焦色，不通过透明度制造多种深浅。
- 总体值和差值由服务端提供，呈现层不从可见明细行重新聚合。

### 结果网格

- 总体带与明细使用相同的列语义；总体不进入明细排序、截行计数或记录投影。
- 空值统一显示破折号；记录的可点性只在悬停或键盘聚焦时出现。
- 组边界只在多层表头中表达；横向滚动时的边缘提示随剩余滚动空间出现。
- 首列作为坐标时保持冻结，以便数字离开视口后仍能识别所属行。

### 整窗读数

整窗读数只消费服务端的 `presentation.totals`。它适用于无业务分组的少量指标，并明确标注实际覆盖期间；下钻沿用该覆盖期间。

## 6. 页面与业务工作台

### 应用壳

页面由画布、导航侧栏和主区白面组成。主区是唯一内容滚动容器；主区内部没有居中定宽层或第二道内容内衬。窄屏配置栏改为浮层，不把结果区和设置区压成并列窄列。

### 清单页骨架

清单页使用页头、控制条和一张裸铺表。档案栏的元信息使用 label–value 网格；长清单先显示计数，展开后再显示成员。

### 报告工作台

- 查看和编辑共用同一渲染结构；标题就地编辑，配置栏保持稳定位置。
- 配置分为筛选、指标和分组三节，次序固定；时间属于页面底栏，不作为第四节。
- 由指标算出的构成占比仍属于指标节；分组排序和最大项数属于分组行自身的设置。
- 成员标题必须从业务目录获得；不能把 ID 当作界面兜底文案。
- 只读回显不伪装成禁用控件；不可用项在选择面中说明原因。

### 时间栏与对照期

时间栏是查询的一等公民，位于页面底栏。相对窗口和绝对窗口表达不同语义；对照期与主期按同一业务坐标对齐，差值不参与下钻。无法执行的组合在选择前禁用并说明原因，不静默改写用户选择。

### 看板页

每块瓦片只有一个动作槽；标题、图表切换和更多动作共用题行。瓦片的结果、加载、空和错误状态使用同一内容区。

### 侧栏系统

推挤式侧栏与主区并列且可折叠；模态侧板负责档案读取并管理遮罩、焦点和关闭。两者不因宽度相近而互换。

### 明细弹层与名单卡

明细弹层承载受控记录投影，不新增聚合结果的第二套图表切换。名单使用清单表而不是结果网格，不将逐人字段放入模型上下文。

### 登录面

登录由门屏和密码卡组成。门屏只负责进入，密码卡只负责邮箱密码；登录专用输入不扩散为控制台通用表单。

## 7. 消费纪律

- 组件只消费语义令牌，不自定颜色、阴影、圆角或排印值。
- 新增跨组件形态先补充本文的判据，再由组件和测试实现；局部组件的具体配方留在组件事实源。
- 公开界面不显示内部寻址信息、物理模型名称或未面向用户的执行字段。
