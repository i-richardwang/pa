# PA 呈现契约

呈现由语义呈现意图、作者视觉设置和服务端确定性编译共同决定。服务端不替声明方猜图型；声明不能
忠实表达数据时退回表格或明确失败，不静默改数、聚合或裁剪。指标计算见 `metric_architecture.md`，
时间语义见 `time_contract.md`，视觉形态见 `ui_spec.md`。

## 合同边界

| 合同 | 内容 | Agent 可见 |
|---|---|---|
| `analysis` | 指标、维度、筛选、时间、受控计算 | 是 |
| `view` | 图型与数据通道 | 是 |
| `view_preferences` | 颜色、线柱覆盖、数值标签、表格色阶 | 否 |

物理执行计划和呈现规格是服务端私有编译产物。Analysis 保存数据问题；View 通过 `analysis_id` 引用它，
保存呈现意图与视觉偏好；Report 只引用 `view_id`。MCP 每次以产品默认视觉偏好创建或重做 View，不能
继承对它不可见的作者设置。

## 图型与通道

| 图型 | 主轴 | 拆分 | 值通道 |
|---|---|---|---|
| 指标卡 | 无 | 无 | 指标；结果不能带维度 |
| 折线 | 时间 | 至多一个维度 | 主、副两把尺子，每侧一种量纲 |
| 柱状图 | 一个维度 | 至多一个维度 | 主、副两把尺子，每侧一种量纲 |
| 饼图 | 一个维度 | 无 | 一个可加指标 |
| 表格 | 声明的列轴 | — | 其余轴落行 |

没有进入任何通道的维度会造成同一坐标多行，因此图形声明不成立；未绘制的指标不会改变数据。拆分
在场时只允许一个值系列。主、副系列不能重叠，每根轴只能容纳一种量纲；三种量纲无法忠实装箱。
线或柱是视觉偏好，不改变主副轴的数据语义。

图型可选性、默认绑定和编辑面板必须读取同一次通道装箱结果。数据前提与可读性预算在编译期按真实
结果判断；图形超限退回表格，表格超过资源上限才拒绝。任何阈值都不能裁剪数据。

编译产物可以携带由结果结构生成的 `structure_title`。作者标题优先，结构标题作为辅助信息；渲染端
不得再次推导。

## 表格

`view.columns` 是有序列轴声明：`time` 表示结果中的逻辑时间桶，`metrics` 表示指标轴，其他值必须是
本次查询的业务分组维度。行轴始终是结果中未进入列轴的轴。

- `time` 是条件轴：结果没有时间成员时退场；业务维度和指标轴缺失则 fail-closed。
- 编辑器只在作者明确调整时写入 `columns`，不把默认布局回写定义。
- 未声明时，有时间轴则时间在列；纯月度无分类结果月份在行、年份在列。
- 显示总体时，业务维度不能进入列轴；开启总体必须原子清除冲突轴。
- 列角色只读结果的 `column_roles`，不根据列名、基数或行数猜测。

交叉表的每个叶子列携带完整 `headerPath`，渲染端按稳定结构键和相邻前缀生成分组表头，不按展示标题
合并。相同坐标出现多行时布局失败；可以明确提供原始长表，但不能声称交叉表已生效。宽表通过横向
滚动承载，不减少列。

## 视觉设置

表格热力色阶属于 `view_preferences`，只适用于表格。每个指标独立计算刻度，总体不参与刻度也不着色；
显式阈值覆盖默认值，但必须与数据域共同形成有序色阶。渲染端只映射颜色与对比文字，不改变数值。

数值标签只适用于折线和柱状图，支持第一主系列或全部系列。拆分系列没有“第一主系列”语义，因此
与前者互斥。空间不足时渲染端可以稀疏标签，但必须保留末点，不能改变声明或数据。

## 聚合值与记录

呈现层禁止指标算术。总体、Top-N 和整窗读数均由服务端按正式指标独立计算，不从可见行求和，也不
平均已计算的率。整窗读数只随指标卡交付；其覆盖期间必须写实，不能整窗合并的指标只声明实际求值的
终点期间。总体的构成占比在总体值非零时为 100%，为空或为零时为空。差值同样由服务端给出，格式和
小数位直接读取结果列合同。

能否查看构成记录只取决于指标是否绑定记录集，与格值是否为零或为空无关。记录投影按当前查看者权限
重放聚合定义并校验完整格点，不信任客户端拼装的成员、过滤器或时间坐标。

## 红线

- 不在呈现层求和、平均、补零或重算指标。
- 不用阈值裁剪数据，不把拒绝与降级混为一谈。
- 不静默改写仍然存在的轴，不按展示标题合并结构节点。
- 不用数值决定记录可点性。
- 不把人类视觉设置加入 MCP schema。
