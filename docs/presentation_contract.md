# PA 呈现契约

结果怎样呈现，由三部分共同决定：语义层的呈现意图、作者的视觉设置，以及服务端确定性的编译。服务端不替声明方挑选图型；声明的图型无法如实表达数据时，改用表格或明确报错，不会悄悄修改、聚合或截断数据。指标计算见 `metric_architecture.md`，时间语义见 `time_contract.md`，界面样式见 `ui_spec.md`。

## 三类定义

| 定义 | 内容 | Agent 可见 |
|---|---|---|
| `analysis` | 指标、维度、筛选、时间、受控计算 | 是 |
| `view` | 图型，以及每个维度和指标放在哪个通道 | 是 |
| `view_preferences` | 颜色、线柱选择、数值标签、表格色阶 | 否 |

物理执行计划和呈现规格都是服务端内部的编译产物。Analysis 保存"问什么数据"；View 通过 `analysis_id` 引用 Analysis，保存呈现意图和视觉偏好；Report 只引用 `view_id`。MCP 每次都用产品默认的视觉偏好创建或重建 View，因为作者设置对 Agent 不可见，也就不能被继承。

## 图型与通道

| 图型 | 主轴 | 拆分 | 数值 |
|---|---|---|---|
| 指标卡 | 无 | 无 | 指标；结果不能带维度 |
| 折线图 | 时间 | 至多一个维度 | 主 Y 轴和副 Y 轴，每根轴只放一种单位 |
| 柱状图 | 一个维度 | 至多一个维度 | 主 Y 轴和副 Y 轴，每根轴只放一种单位 |
| 饼图 | 一个维度 | 无 | 一个可加总的指标 |
| 表格 | 声明的列轴 | — | 其余维度放在行上 |

每个维度都必须放进某个通道。如果有维度没有放进任何通道，同一个坐标上就会出现多行数据，这个图型就不能用；没有画出来的指标则不影响数据。使用拆分维度时，只能有一个指标。主轴和副轴上的指标不能重复，每根轴只能放一种单位（例如人数、百分比），所以一张图最多容纳两种单位，出现第三种就无法如实画出。画成线还是柱只是视觉偏好，不改变指标在主副轴上的归属。

哪些图型可选、默认怎样绑定通道、编辑面板显示哪些选项，三者必须来自同一次通道分配的计算结果。数据条件和可读性限制在编译时按真实结果判断：图形超出限制时改用表格，表格超出资源上限时才拒绝。任何阈值都不能用来截断数据。

编译产物可以带一个根据结果结构生成的 `structure_title`。有作者标题时优先显示作者标题，结构标题作为辅助信息；前端不再自行生成标题。

## 表格

`view.columns` 按顺序声明列轴：`time` 表示结果里的逻辑时间桶，`metrics` 表示指标，其他值必须是本次查询的业务分组维度。没有放进列轴的维度都放在行上。

- `time` 是可选的：结果里没有时间维度时，它不生效。但声明的业务维度或 `metrics` 在结果里找不到时，直接报错。
- 编辑器只在作者主动调整布局时写入 `columns`，不把默认布局写回定义。
- 没有声明 `columns` 时：结果有时间维度就把时间放在列上；只有月份、没有其他分组的结果，月份放在行上、年份放在列上。
- 显示总计时，业务维度不能放在列轴上；开启总计的同一次操作里要把冲突的维度从列轴移走。
- 每一列的角色只读取结果里的 `column_roles`，不根据列名、取值个数或行数推断。

交叉表的每个最底层列都带有完整的 `headerPath`。前端按稳定的结构键和相邻列的共同前缀生成分组表头，不根据显示标题合并表头。同一个坐标出现多行时，交叉表布局失败；这时可以明确地改为展示原始长表，但不能显示成交叉表已经生效的样子。列很多的宽表通过横向滚动完整显示，不删减列。

## 视觉设置

表格热力色阶属于 `view_preferences`，只用于表格。每个指标单独计算色阶范围；总计既不参与计算范围，也不着色。作者设置的阈值会覆盖默认值，但必须和数据范围一起构成有序的色阶。前端只负责上色和调整文字对比色，不改变数值。

数值标签只用于折线图和柱状图，可以选择只标第一个主系列或标全部系列。使用拆分维度时没有"第一个主系列"，所以这时不能选前者。空间不够时前端可以隐藏部分标签，但必须保留最后一个点的标签，并且不能改变声明或数据。

## 汇总值与明细

前端不对指标做任何运算。总计、Top-N 和整段合计都由服务端按指标定义单独计算，不把可见行加起来，也不对已经算好的比率求平均。整段合计只随指标卡返回，并如实标明覆盖的期间；不能对整段期间汇总的指标，只标明实际计算的那个终点期间。总计行的构成占比在总体值不为零时是 100%，为空或为零时为空。差值同样由服务端计算，格式和小数位直接读取结果里列的定义。

能不能查看构成某个数值的明细记录，只取决于该指标是否绑定了记录集，与单元格的值是否为零或为空无关。查看明细时，服务端按当前查看者的权限重新执行汇总定义，并校验完整的单元格坐标，不信任客户端拼出来的成员、筛选条件或时间坐标。
